# Omkar AI Labs Website

A static, responsive landing page for a student-led AI and software innovation initiative.

## Important
This website intentionally describes Omkar AI Labs as a **student-led initiative**. It does not claim that the initiative is incorporated, funded, or established in a particular year.

## Files
- index.html
- styles.css

## Run locally
Open `index.html` in a browser.

## Deploy
You can deploy the folder to GitHub Pages, Netlify, Vercel, or another static hosting service.

Before using the URL for any application, make sure the site accurately represents your real situation.
